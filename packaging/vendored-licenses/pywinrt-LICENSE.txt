Vendored by packaging/notices.py -- not part of these packages' own distributions.

The nine `winrt-*` packages (winrt-runtime and the eight winrt-windows-* API projection
packages bleak's Windows BLE backend pulls in) are all generated and published together
by the pywinrt project, and their wheels ship no license file of any kind -- verified
directly against winrt-runtime 3.2.1: the wheel contains only INSTALLER, METADATA,
RECORD, top_level.txt and WHEEL. Each one's own METADATA does declare
`License-Expression: MIT`, so the omission is a packaging gap, not an unlicensed
dependency -- the same text below covers all nine, since they come from one upstream
project and one license file.

Pulled unmodified, 2026-09-13, from the project's own repository:
