# The A/B tour: one pass over every screen whose paint has ever been optimised, plus a real
# dialog. Run it, revert `meshterm/` on the device, run it again — same panel, same database,
# same radio, minutes apart. That is the only honest before/after this app has.
#
# The dialog group is the quit confirm over the main menu: the easiest real dialog to reach
# from anywhere, and safe to drive because only the arrows and Esc are sent (Enter would
# commit the right-hand button, which is Quit).
#
# Read `dialog-keys`, not `dialog-open`/`dialog-close` — an Esc reading is console-quiescence
# overshoot, and a paint that lands outside the window reports a false-fast 7-byte result.
